# Pasta de Recursos

Esta pasta contém recursos visuais da aplicação.

## Ícone da Aplicação

Para adicionar um ícone à aplicação:

1. Coloque o ficheiro `icon.png` nesta pasta (`resources/`)
2. O ícone deve ter formato PNG
3. Tamanho recomendado: 64x64 pixels ou 128x128 pixels
4. A aplicação carregará automaticamente o ícone ao iniciar

**Nota:** Se o ficheiro não existir ou houver erro ao carregá-lo, a aplicação continuará a funcionar normalmente sem ícone.
