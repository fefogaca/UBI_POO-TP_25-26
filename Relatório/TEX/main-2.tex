\section*{Resumo}
\hspace{10pt}
Este relatório documenta a evolução de um sistema de gestão de farmácia desenvolvido no âmbito da disciplina de Programação Orientada a Objetos. A segunda entrega introduziu uma interface gráfica baseada em Java Swing, persistência de dados através de serialização de objetos, testes unitários JUnit 5 e documentação com JavaDoc. O código foi reorganizado em pacotes (\texttt{app}, \texttt{modelo}, \texttt{gui}, \texttt{persistencia}, \texttt{test}) e beneficiou de refatoração orientada por princípios de POO, resultando numa aplicação mais robusta, reutilizável e preparada para futuras extensões.

\subsection{Âmbito, enquadramento e motivação}
\hspace{10pt}
Este documento descreve o Trabalho Prático 2 (TP2) da disciplina, que dá continuidade ao sistema originalmente desenvolvido no TP1.     \item \textbf{Documentação Contínua}: manutenção do JavaDoc e do relatório técnico (\texttt{CONTEXTO.md}) alinhados com o estado do código.

\section{Estrutura da Solução Construída}

\subsection{Visão Geral}
O código encontra-se organizado por responsabilidade:
\begin{itemize}
    \item \textbf{Pacote \texttt{app}}: ponto de entrada \texttt{Main}.
    \item \textbf{Pacote \texttt{modelo}}: domínio da aplicação (entidades e regras).
    \item \textbf{Pacote \texttt{gui}}: interface Swing (janela principal e painéis).
    \item \textbf{Pacote \texttt{persistencia}}: gestão de ficheiros para serialização.
    \item \textbf{Pacote \texttt{test}}: testes JUnit 5.
\end{itemize}

\subsection{Detalhamento dos Ficheiros}
\begin{itemize}[leftmargin=15pt]
    \item \textbf{\texttt{src/app/Main.java}}: Carrega dados, inicializa \texttt{Farmacia} e arranca a GUI. Lança a aplicação na Event Dispatch Thread.
    \item \textbf{\texttt{src/modelo/Pessoa.java}}: Classe abstrata base com nome e NIF. Obriga subclasses a implementar \texttt{toString()}.
    \item \textbf{\texttt{src/modelo/Cliente.java}}: Extende \texttt{Pessoa}, adiciona \texttt{Morada} e serialização. Representa clientes da farmácia.
    \item \textbf{\texttt{src/modelo/Morada.java}}: Value object com rua, cidade e código postal.
    \item \textbf{\texttt{src/modelo/Vendavel.java}}: Interface com \texttt{getNome()} e \texttt{getPreco()}.
    \item \textbf{\texttt{src/modelo/Produto.java}}: Implementa \texttt{Vendavel}; gere ID, preço e stock, com métodos de validação.
    \item \textbf{\texttt{src/modelo/Encomenda.java}}: Relaciona cliente e produtos, controla estados, calcula preço total, oferece construtores sobrecarregados.
    \item \textbf{\texttt{src/modelo/Farmacia.java}}: Núcleo da lógica; gere listas, valida operações, ajusta stock e estados.
    \item \textbf{\texttt{src/persistencia/GestorDados.java}}: Serializa/desserializa dados para \texttt{farmacia.dat}; atualiza contadores de IDs.
    \item \textbf{\texttt{src/gui/FarmaciaGUI.java}}: \texttt{JFrame} com \texttt{JTabbedPane}; trata encerramento com opção de guardar.
    \item \textbf{\texttt{src/gui/PainelGestaoClientes.java}}: Tabela e formulários para CRUD de clientes, com validação de NIF (9 dígitos) e código postal (0000-000), permitindo correção de NIF apenas neste contexto.
    \item \textbf{\texttt{src/gui/PainelGestaoProdutos.java}}: Gestão de produtos com validação de stock/preço e atualização da tabela.
    \item \textbf{\texttt{src/gui/PainelGestaoEncomendas.java}}: Gestão completa de encomendas (seleção de cliente, seleção/pesquisa de produtos, certificação de stock, atualização de estado e sincronização com painel de produtos), apresentando o cliente apenas para consulta durante a edição e com diálogo de gestão que oferece ações de adicionar, remover e guardar alterações.
    \item \textbf{\texttt{src/test/FarmaciaTest.java}}: Testes unitários que asseguram regras de negócio (clientes, encomendas, stock).
    \item \textbf{\texttt{lib/junit-platform-console-standalone-1.10.2.jar}}: Dependência JUnit 5.
    \item \textbf{\texttt{doc/}}: JavaDoc gerado.
    \item \textbf{\texttt{farmacia.dat}}: Ficheiro de dados serializados (não versionado).
    \item \textbf{\texttt{CONTEXTO.md}}: Documento de referência técnica.
\end{itemize}

\section{Funcionalidades Implementadas}
\begin{itemize}
    \item Interface gráfica com três separadores: Clientes, Produtos e Encomendas.
    \item CRUD completo para clientes e produtos, com validação de NIF (9 dígitos) e código postal (0000-000).
    \item Registo, edição (incluindo atualização de stock/estado) e remoção de encomendas com sincronização imediata do stock e cliente apresentado apenas para consulta durante edições.
    \item Diálogo dedicado ao ajuste de produtos da encomenda, com ações de adicionar, remover e guardar alterações.
    \item Persistência automática ao terminar a sessão (com confirmação).
    \item Validações de dados (NIF único, formato de código postal, stock suficiente, preço/stock não negativos).
    \item Testes unitários para garantir a consistência da lógica.
\end{itemize}

\subsection{Classe FarmaciaGUI}
\begin{lstlisting}[caption={Configuração da janela principal em FarmaciaGUI.java}]
public class FarmaciaGUI extends JFrame {
    public FarmaciaGUI(Farmacia farmacia) {
        setTitle("Gestão de Farmácia");
        setSize(800, 600);
        setDefaultCloseOperation(JFrame.DO_NOTHING_ON_CLOSE);
        setLocationRelativeTo(null);

        addWindowListener(new WindowAdapter() {
            @Override
            public void windowClosing(WindowEvent e) {
                int confirm = JOptionPane.showConfirmDialog(
                    null,
                    "Deseja guardar os dados antes de sair?",
                    "Sair",
                    JOptionPane.YES_NO_CANCEL_OPTION
                );
                if (confirm == JOptionPane.YES_OPTION) {
                    GestorDados.guardarDados(
                        farmacia.getClientes(),
                        farmacia.getProdutos(),
                        farmacia.getEncomendas()
                    );
                    dispose();
                    System.exit(0);
                } else if (confirm == JOptionPane.NO_OPTION) {
                    dispose();
                    System.exit(0);
                }
            }
        });

        JTabbedPane tabbedPane = new JTabbedPane();
        PainelGestaoClientes painelClientes = new PainelGestaoClientes(farmacia);
        PainelGestaoProdutos painelProdutos = new PainelGestaoProdutos(farmacia);
        PainelGestaoEncomendas painelEncomendas =
            new PainelGestaoEncomendas(farmacia, painelProdutos);

        tabbedPane.addTab("Clientes", painelClientes);
        tabbedPane.addTab("Produtos", painelProdutos);
        tabbedPane.addTab("Encomendas", painelEncomendas);
        add(tabbedPane);
    }
}
\end{lstlisting}

\subsection{Classe GestorDados}
\begin{lstlisting}[caption={Persistência em GestorDados.java}]
public static void guardarDados(
        List<Cliente> clientes,
        List<Produto> produtos,
        List<Encomenda> encomendas) {
    try (ObjectOutputStream oos =
             new ObjectOutputStream(new FileOutputStream(NOME_FICHEIRO))) {
        oos.writeObject(clientes);
        oos.writeObject(produtos);
        oos.writeObject(encomendas);
    } catch (IOException e) {
        System.err.println("Erro ao guardar os dados: " + e.getMessage());
    }
}

@SuppressWarnings("unchecked")
public static Object[] carregarDados() {
    File f = new File(NOME_FICHEIRO);
    if (!f.exists()) {
        return null;
    }
    try (ObjectInputStream ois =
             new ObjectInputStream(new FileInputStream(NOME_FICHEIRO))) {
        List<Cliente> clientes = (List<Cliente>) ois.readObject();
        List<Produto> produtos = (List<Produto>) ois.readObject();
        List<Encomenda> encomendas = (List<Encomenda>) ois.readObject();

        if (!produtos.isEmpty()) {
            int maxIdProduto = produtos.stream()
                    .mapToInt(Produto::getId).max().orElse(0);
            Produto.setProximoId(maxIdProduto + 1);
        }
        if (!encomendas.isEmpty()) {
            int maxIdEncomenda = encomendas.stream()
                    .mapToInt(Encomenda::getId).max().orElse(0);
            Encomenda.setProximoId(maxIdEncomenda + 1);
        }
        return new Object[]{clientes, produtos, encomendas};
    } catch (IOException | ClassNotFoundException e) {
        System.err.println("Erro ao carregar os dados: " + e.getMessage());
        return null;
    }
}
\end{lstlisting}

\section{Considerações de Implementação}
\begin{itemize}
    \item Utilização de encapsulamento e validações para garantir consistência (e.g., stock não negativo).
    \item Regras de formato para NIF (9 dígitos) e código postal (0000-000), com correção restringida ao painel de clientes.
    \item Dedução e reposição automáticas de stock ao registar/remover encomendas.
    \item Atualização de identificadores estáticos após carregamento da persistência para evitar colisões.
    \item Sincronização entre os painéis de encomendas e produtos para refletir alterações de stock imediatamente.
\end{itemize}
